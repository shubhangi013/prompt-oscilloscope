# Contributing

Prompt Oscilloscope requires Node.js 22+ and pnpm 10.17.1.

```sh
corepack enable
pnpm install
pnpm validate
```

Keep changes focused and add tests for behavioral changes. Tests must not call TypeSafe AI or GitHub Copilot services; use injected analyzers and ACP subprocess fixtures instead.
